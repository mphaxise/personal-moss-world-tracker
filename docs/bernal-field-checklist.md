## Before you start

- Pick a walk start and end.
- Open a map app for rough coordinates.
- Take one cover image if the neighborhood feels good right away.
- For each stop, get one hero image before overthinking taxonomy.

## Scoring shorthand

- `V` = visual distinctiveness
- `S` = story strength
- `P` = photo opportunity
- `A` = public accessibility

Score each from `1` to `3`.

Decision shorthand:
- `PUB` = publish candidate is strong
- `HOLD` = promising but needs another pass
- `DROP` = weak, repetitive, unsafe, or too private

## Stop pass

For each stop, capture:
- one photo
- one sentence for `what is happening here`
- one sentence for `why here`
- one rough location note
- one decision: `PUB`, `HOLD`, or `DROP`
