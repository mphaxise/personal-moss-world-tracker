# Bernal Heights Moss Atlas Field Worksheet

Date: 2026-03-15
Status: field-use template

## Purpose

Use this worksheet during Bernal scouting walks to turn candidate stops into `field-verified` stops or drop them quickly.

This is the bridge between the planning pack in `docs/bernal-content-pack.md` and the first real atlas content file.

## How to use it

For each candidate stop:
- pause long enough to evaluate the site honestly
- capture one hero image and one short field note
- decide `publish`, `hold`, or `drop`
- avoid overclaiming species certainty from a casual pass

Recommended tools:
- phone camera
- notes app or printed copy of this worksheet
- maps app for rough coordinates
- one spare line for route notes between stops

## Quick scoring guide

Use a simple 1 to 3 score.

- `1` = weak
- `2` = usable
- `3` = strong

Score these dimensions:
- visual distinctiveness
- story strength
- photo quality opportunity
- public accessibility

Decision rule:
- `publish` if most scores are `3` and the stop has a clear story
- `hold` if the site is promising but needs a better image or second visit
- `drop` if the stop is repetitive, weak, private, or unsafe

## Post-walk synthesis

After the walk, sort all candidates into three buckets:

### Publish now

Stops that are:
- visually strong
- easy to explain
- safe to visit
- worth a dedicated atlas card

### Hold for second visit

Stops that are:
- seasonally promising
- hard to photograph well on first pass
- missing confidence on story or habitat claim

### Drop

Stops that are:
- too weak
- repetitive
- unsafe
- too dependent on private property

## Conversion checklist

Before a stop moves into the atlas JSON, make sure it has:
- final working title
- final location hint
- rough or exact coordinates
- one selected hero image
- one sentence summary
- one `why this spot matters` note
- one habitat label
- one seasonality note
- one source ID or field note ID
- status set to `field-verified` or `published`
